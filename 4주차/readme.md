# 게임프로그래밍 4주차 수업(1002)

게임프로그래밍(c01)복습

gotoxy()는 초창기의 텍스트모드다

커서 제어 위치와 화면 지우기

cls는 클리어 스크린이다 화면이 지워진다

키 입력으로 들어오는 건 두 가지

아스키코드와 스캔코드

중요한 거는 방향키, 스캔코드를 이용해서 방향키 지정

홈키 엔드키도 마찬가지

사각형그리기, 정사각형표현, 깨진 정사각형 분석하여 바로잡음

음식이름 출력

난수배움srand시드

일정한 난수를 발생한다

가변인수

parameter 개수가 세 개면 argument도 세 개다

가변인수는 하나씩 처리해준다
